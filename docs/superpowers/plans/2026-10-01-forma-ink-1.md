# Forma Ink 1 Implementation Plan

> **For agentic workers:** executed by Claude inline (superpowers:executing-plans) in a git worktree on `feat/forma-ink`. Steps use checkbox (`- [ ]`) syntax.
>
> **Workflow rule (user, 2026-10-01):** add no new test files and no new test cases. Each task is verified by typecheck and build, plus a browser walkthrough driven through the preview tools, with screenshots and console checks. The only edits to existing tests are those that replacing `WorkingPaper` breaks.

**Goal:** a stylus notebook and whiteboard (Forma Ink 1) with our own ink engine, course-aware inserts, export, and on-device handwriting → LaTeX. It replaces `WorkingPaper`.

**Architecture:**
- A framework-free package, `@forma/ink`, holds:
  - the model;
  - the ops and undo history;
  - geometry, a spatial index and a camera;
  - a three-layer canvas renderer;
  - pointer input with palm rejection;
  - the tools, and export.
- `apps/web` wraps it in React:
  - `<InkCanvas>` and the toolbar;
  - the `/ink` routes;
  - a Dexie store;
  - MathLive equations;
  - plate and bank inserts;
  - a web worker running pix2text-MFR through transformers.js.

**Tech stack:** TypeScript, Canvas 2D, Pointer Events, `perfect-freehand`, zod, Dexie, MathLive, KaTeX, `pdf-lib`, `@huggingface/transformers` (onnxruntime-web: WebGPU, falling back to WASM), Next 16, React 19.

**Spec:** `docs/superpowers/specs/2026-10-01-forma-ink-design.md`

## Global Constraints

- Colours come only from Forma tokens (`var(--ink)`, `var(--graphite)`, `var(--charge)`, `var(--field)`, `var(--flux)`, `var(--surface)`). The canvas resolves them with `getComputedStyle` at draw time, so the theme switches live. No hex in components.
- Coordinates are stored in world units (CSS px at zoom 1). Stroke size is in world units, so ink keeps its weight at every zoom.
- Every page mutation goes through an `Op`. Ops are validated by zod before they are applied, and an invalid op is dropped and logged.
- No new dependencies beyond these:
  - `perfect-freehand`, `mathlive`, `pdf-lib` and `@huggingface/transformers` in the products;
  - `@huggingface/transformers` in a scratchpad-only Node benchmark for the spike.
- Keep `js-draw` installed: Plan M (Commons) still uses it until Ink 2.
- Performance targets:
  - ink within 16 ms of input;
  - 60 fps pan and zoom with 5,000 strokes;
  - a 5,000-item page opens in under 1 s.
- Copy voice: plain, exact and warm. No emoji in the UI.

## Review Focus

1. **A palm on a pen device.** After any pen event, touches must never ink: they pan and zoom. Checked in Task 3's walkthrough with synthetic touch-then-pen sequences.
2. **Closing the tab mid-debounce.** The last stroke must survive a reload: flush on `pagehide` and `visibilitychange`. Checked in Task 5.
3. **One gesture is one undo.** Moving or scaling 50 lassoed items, or a precise erase that splits 10 strokes, undoes in a single step. Checked in Task 4.
4. **Zoom extremes.** Strokes drawn at 800% and at 10% keep their world size and stay hit-testable. Checked in Task 3.
5. **Storage blocked** (private mode or quota). The editor still works in memory, shows a banner, and export still works. Checked in Task 5 by stubbing `indexedDB.open` to throw.


```ts
// ops.ts
export type Op =
  | { type: "add"; items: Item[] }
  | { type: "remove"; items: Item[] }               // carries the full items, so it inverts to add
  | { type: "update"; before: Item[]; after: Item[] } // same ids, same order
  | { type: "reorder"; ids: string[]; before: number[]; after: number[] };
export const OpSchema: z.ZodType<Op>;
export function invert(op: Op): Op;
export function apply(items: Map<string, Item>, op: Op): void; // mutates; validates first and throws InvalidOp on failure
export class InvalidOp extends Error {}
```

```ts
// history.ts
export class History {
  constructor(items: Map<string, Item>, onChange: (op: Op, origin: "do" | "undo" | "redo") => void);
  begin(): void;                 // opens a group
  push(op: Op): void;            // applies op and records it (in the open group, or a single-op group)
  end(): void;                   // closes the group (no-op if empty)
  undo(): boolean; redo(): boolean;
  canUndo(): boolean; canRedo(): boolean;
}
```

```ts
  destroy(): void;
}
// touch-action: none on el. Moves use getCoalescedEvents() (falling back to [e]) and getPredictedEvents() (falling back to []).
// Two simultaneous touches drive pan and pinch. A tap is 2 or 3 touches down and up within 250 ms, moving < 10 px.
```

```ts
// shapes.ts
export type ShapeGuess = { shape: ShapeItem["shape"]; pts: Vec[]; score: number } | null;
export function recognizeShape(points: Vec[]): ShapeGuess;
// Resample to 64 points, then:
//   line:      max deviation from the endpoint chord < 6% of its length (arrow if the last 15% has a hook ≥ 25°);
//   closed:    endpoint gap < 15% of perimeter → corner detection (turn angle > 50° on smoothed points):
//              3 corners → triangle, 4 with ~right angles → rect, more → polygon;
//              ellipse when the radius from the centroid has a coefficient of variation < 0.12 (fit the axis-aligned bounds).
// Returns null if nothing fits (score < 0.8).
```

- [ ] **Step 1: Implement:**
  - **Highlighter:** the pen with `tool: "highlighter"`.
  - **Stroke eraser:** while moving, removes strokes with `distToStroke < r` (r = 8/zoom), with one `remove` op per touched stroke inside a gesture group.
  - **Precise eraser:** replaces each touched stroke by `splitStroke` pieces through an `update`-equivalent remove+add inside one group.
